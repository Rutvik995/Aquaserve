# Aquaserve

Aquaserve is a Kotlin-based mobile application designed to streamline water delivery management, customer ordering, and service tracking.

## Features
- **Order Management:** Place, manage, and view status of water delivery requests.
- **User Dashboard:** Tracks past orders, payment history, and delivery schedules.
- **Clean UI:** Native Android interface for smooth user interactions.

## Tech Stack
- **Language:** Kotlin
- **Platform:** Android SDK
- **Architecture:** MVVM (Model-View-ViewModel)
- **UI Framework:** Jetpack Compose / XML Layouts
